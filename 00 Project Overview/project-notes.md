# OpenWrt Home Lab

## Overview

This project documents the setup and configuration of an OpenWrt home lab built to improve my networking and Linux administration skills through practical, hands-on experience.

Using a Xiaomi Mi Router AC2100 running OpenWrt 23.05.5, I configured core networking features, tested each change and documented the results throughout the project.

## Objectives

- Gain hands-on experience with OpenWrt.
- Learn the basics of network administration.
- Improve Linux command-line skills using SSH.
- Practise documenting configuration changes and testing.
- Build a portfolio project for IT infrastructure and support roles.

## Hardware

- Xiaomi Mi Router AC2100
- Windows 10 Desktop

## Software
