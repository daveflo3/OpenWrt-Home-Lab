# SSH Administration

## Objective

Connect to the OpenWrt router securely using SSH and perform basic system administration tasks from the command line.

## What I did

- Connected to the router from Windows PowerShell using SSH.
- Verified the installed OpenWrt version and Linux kernel.
- Checked the router hostname.
- Viewed network interfaces and IP addressing.
- Reviewed the routing table.
- Checked storage usage, memory usage and system uptime.
- Explored the Linux filesystem.

## Commands Used

- ssh
- cat
- uname
- ip address
- ip route
- df -h
- free
- uptime
- ls

## What I learned

This project gave me hands-on experience using the Linux command line to manage a network device. I learned how to inspect system information, verify network configuration, review routing, monitor system resources and navigate the filesystem without using a graphical interface.
